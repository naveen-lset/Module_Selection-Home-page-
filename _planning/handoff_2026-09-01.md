### Acceptance — what to try, and what you should see

- **Record sheet.** Tap the Maintenance card on a Site. You should get a centred
  sheet headed *Maintenance* with ~39 fields in 6 groups, scrolled to *Open Work
  Orders*. If it announces "Opening Maintenance" and nothing opens, the domain
  has no record — run `antz.checkDetail()`, which should return `[]`.
- **Sites listing.** Press *Site Command Centre*. You should land on the Sites
  listing (`#sites`, four rows), from any depth, even when the tab is already
  selected. If you land inside a Site, you are on a cached build — hard-reload.
- **Modules dialog.** Press ☰ in the Site header. It should be centred, the page
  behind it blurred and unscrollable, each row reading only "N widgets". If it
  hangs off the left edge, that is the old build.
- **Chrome.** The switcher should be the first thing under the status bar, with
  "Good Morning, Sourav Tambe" beneath it in both views, and no coloured line
  down the left edge of a Site row.
- **Search hint.** Watch the empty field for ~5s: the word after *Search* should
  change (Animals → Enclosures → …). Click into it and it should freeze. If it
  never moves, the OS has reduce-motion on — that is deliberate; you get one
  static line instead.
- **Landing.** Reload, or switch Site. Cards should rise and sharpen bottom-up
  over ~0.9s. If they all appear together, check `antz.land()` in the console;
  if that cascades and a reload does not, the trigger list is the bug, not the
  animation.
